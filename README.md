A tiny Python program that writes a single username word, `witty-lynx-50-3813`, to `entry.txt` — one word, nothing else. It uses only the Python standard library, needs no network, and is fully deterministic: every run produces the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` to the output directory with mode 0644.
